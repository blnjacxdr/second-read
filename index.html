How do these differ?
Gemini Nano
A smaller Gemini model built into Chrome on some laptops. It reads the essays for hours, titles and awards, and nothing leaves the laptop.
Gemini in the cloud
The closest read: it reads the whole application at once and usually finds the most. The text goes to Google's servers, only if you pick it. Google doesn't train on it, and every word sent is listed.
Code checks only
Fast and exact, but they only catch what they have a rule for, so they miss plenty. A clean result isn't a sign-off.
Where do I get the PDF?
  1. Ask the student to open Common App and go to My Colleges.
  2. Pick one college, then open Review and submit.
  3. Click Print preview, download the PDF it opens, and send it to you.
  4. Drop that file above. About a minute, start to finish.
